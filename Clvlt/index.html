สถาปัตยกรรมการเก็บข้อมูลถาวร (Production Clean State)

  • ฐานข้อมูลพร้อมใช้งานจริง: เริ่มต้นเป็นค่าว่าง 100% ปราศจากข้อมูลจำลอง เชื่อมต่อ Cloud Firestore และมี LocalStorage สำรองอัตโนมัติ
  • รองรับไฟล์ขนาดใหญ่ระดับ GB: แนะนำให้เชื่อมต่อกับ Cloudflare R2 หรือ AWS S3 สำหรับเก็บตัวไฟล์จริง และสร้าง Signed URLs เฉพาะรายการที่ตั้งเป็นส่วนตัว
  • ลิงก์ถาวรไม่หลุด: ใช้ระบบ ID อ้างอิงในฐานข้อมูล หากเจ้าของแก้ไขไฟล์หรือข้อมูล ลิงก์เดิมที่แชร์ไปแล้วจะยังใช้งานได้ตลอดไป
