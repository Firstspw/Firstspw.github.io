Live Firebase Self-Test, 6-Point Security Audit & Production Guide

สถานะฐานข้อมูล: กำลังตรวจสอบ...

1. Firebase Auth First & UID Ownership

ยืนยันตัวตนก่อนเชื่อมต่อ Firestore และผูก ownerUid อัตโนมัติ

2. SHA-256 PIN Hashing + Brute-Force Lock

ไม่เก็บรหัส PIN เป็นข้อความดิบ ใช้แฮช SHA-256 และล็อก 30 วินาทีหากกรอกผิด 5 ครั้ง

3. Strict DOM XSS Sanitization

สร้างการ์ดและข้อความผู้ใช้ผ่าน document.createElement + textContent ทุกจุด

4. Executable Block & Image Compression

บล็อก .exe/.bat/.cmd/.sh/.vbs/.msi/.scr/.ps1 และบีบอัดรูปภาพอัตโนมัติ

5. Instant Public/Private & Deep-Link Guard

ปิดสาธารณะหรือหมดอายุปุ๊บ ซ่อนจากฟีดและบล็อกลิงก์ ?v=ID ทันที

6. Mobile-First UI, QR Code & Web Share

รองรับปุ่มขนาด 44px+, Bottom Sheet, QR Code และ Web Share API

1. การเก็บไฟล์ขนาดใหญ่ระดับหลาย GB แบบถาวรไม่หาย (Cloudflare R2 / AWS S3)

ฐานข้อมูล Cloud Firestore เหมาะสำหรับเก็บข้อมูลเมตา ลิงก์ และไฟล์ขนาดไม่เกิน 1 MB หากต้องการรองรับไฟล์วิดีโอหรือไฟล์ ZIP ขนาดใหญ่ระดับหลาย GB แนะนำให้เชื่อมต่อกับ Cloudflare R2 (ฟรีพื้นที่ 10 GB/เดือน และฟรีค่าดาวน์โหลดไม่จำกัด) โดยเก็บ URL ของไฟล์ไว้ใน Firestore ทำให้ลิงก์แชร์ถาวร ไม่หลุด และโหลดเร็วทั่วโลก

2. ลิงก์ไม่หลุดและป้องกันการแอบเปิดไฟล์ส่วนตัว (Signed URLs + Stable Slug)

ใช้ลิงก์กลางของเว็บ (?v=itemId) เป็นตัวกลางเสมอ แม้จะอัปเดตไฟล์ใหม่เบื้องหลัง ลิงก์ที่แชร์ให้เพื่อนไปแล้วก็ยังใช้งานได้เหมือนเดิม และเมื่อเจ้าของกดปิดเป็นส่วนตัว ระบบหลังบ้านจะระงับการออก Signed URL ทำให้ไม่สามารถเข้าถึงไฟล์ตรงได้

3. กฎความปลอดภัยระดับเซิร์ฟเวอร์ (Firebase Firestore Security Rules) & Custom Domain

นำไฟล์ HTML นี้ขึ้นโฮสต์ฟรีบน Vercel หรือ Cloudflare Pages พร้อมผูกโดเมนสั้น ๆ (เช่น vltly.app / clvlt.com) และตั้งค่า Firestore Rules ดังนี้: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/vault_items/{itemId} {
      allow read: if resource.data.isPublic == true
                  || (request.auth != null && resource.data.ownerUid == request.auth.uid);
      allow create: if request.auth != null
                    && request.resource.data.ownerUid == request.auth.uid;
      allow update, delete: if request.auth != null
                            && resource.data.ownerUid == request.auth.uid;
    }
  }
}
