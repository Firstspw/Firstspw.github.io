ยังไม่มีรายการในฟีดสาธารณะ

เริ่มต้นฝากไฟล์หรือแชร์ลิงก์แรกของคุณ แล้วเปิดสถานะ "สาธารณะ" เพื่อให้คนอื่นในเครื่องอื่นเห็นและดาวน์โหลดได้ทันที

ฝากไฟล์หรือฝากลิงก์ใหม่

เปิดเป็นสาธารณะ (Public)

คนอื่นในเครื่องอื่นจะเห็นและดาวน์โหลดรายการนี้ได้ทันที

แชร์รายการนี้ให้คนอื่น

สแกน QR Code หรือคัดลอกลิงก์ด้านล่างส่งให้เพื่อนเปิดจากเครื่องอื่นได้ทันที

จัดการสิทธิ์เจ้าของ (PIN)

กรอกรหัส PIN 4 หลักที่คุณตั้งไว้ตอนอัปโหลด เพื่อเปิดสิทธิ์แก้ไข เปิด/ปิดสาธารณะ หรือลบรายการของคุณจากเครื่องอื่น

ข้อเสนอแนะสำหรับนำไปใช้งานจริงระยะยาว (Production):

• ตั้งค่า Firestore Rules ให้อ่านสาธารณะเฉพาะเอกสารที่ isPublic == true หรือเป็นเจ้าของ

• หากต้องการฝากไฟล์ขนาดใหญ่ระดับ GB (วิดีโอ/โปรแกรม) ให้เชื่อมต่อ Cloudflare R2 หรือ Firebase Storage
